# Security policy

Please **do not** open public issues for security vulnerabilities.

Report them privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) or by
e-mail to <marcelomatusacuna@gmail.com>. We aim to acknowledge reports
within 5 working days and to agree a disclosure date with the reporter.

Supported versions: the latest release and the `master` branch. Customers
with a commercial or support contract (Black Bear Engineering SpA) receive
fixes for their LTS branch.
