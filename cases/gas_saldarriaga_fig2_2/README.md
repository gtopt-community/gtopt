# gas_saldarriaga_fig2_2 — gas network e2e case

Native gas elements generated by `gasnet2gtopt` (Python API
`build_native`) from
`scripts/gasnet2gtopt/cases/literature/saldarriaga_phd_fig2_2.gasnet.json` with
the study
switches `{"compressor": "series"}`.

The expected objective is 752.606855. It comes from the prototype's
independent scipy/HiGHS LP of the same model, stored in
`scripts/gasnet2gtopt/cases/literature/expected.json`. The goldens under `output/`
come from gtopt and match it to 1e-5 relative, with pressures within
0.01 bar. `scripts/gasnet2gtopt/tests/test_gtopt_integration.py`
re-checks this against the expected values.

## Source

C. A. Saldarriaga Cortés, *Planeamiento Integrado de Sistemas
Energéticos: Un Enfoque Estocástico Multietapa*, doctoral thesis,
Universidad Tecnológica de Pereira, 2018, Fig. 2.2(b), pp. 25–26,
<https://hdl.handle.net/11059/10887>.  Only the numeric data of the
figure (pipe constant, pressures, flows) is used.
