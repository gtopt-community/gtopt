# gas_mini3 — gas network e2e case

Native gas elements generated by `gasnet2gtopt` (Python API
`build_native`) from `scripts/gasnet2gtopt/cases/mini3.gasnet.json` with the study
switches `{"(defaults)": true}`.

The expected objective is 94323.585100. It comes from the prototype's
independent scipy/HiGHS LP of the same model, stored in
`scripts/gasnet2gtopt/cases/tiny_expected.json`. The goldens under `output/`
come from gtopt and match it to 1e-5 relative, with pressures within
0.01 bar. `scripts/gasnet2gtopt/tests/test_gtopt_integration.py`
re-checks this against the expected values.
