# gas_belgian_a1_radial — gas network e2e case

Native gas elements generated by `gasnet2gtopt` (Python API
`build_native`) from `scripts/gasnet2gtopt/cases/literature/belgian_a1_radial.gasnet.json` with the study
switches `{"compressor": "series"}`.

The expected objective is 8849.433379. It comes from the prototype's
independent scipy/HiGHS LP of the same model, stored in
`scripts/gasnet2gtopt/cases/literature/expected.json`. The goldens under `output/`
come from gtopt and match it to 1e-5 relative, with pressures within
0.01 bar. `scripts/gasnet2gtopt/tests/test_gtopt_integration.py`
re-checks this against the expected values.

encoded in LANL GasModels.jl (`examples/data/matgas/A1.m`,
<https://github.com/lanl-ansi/GasModels.jl>).  GasModels.jl is

full text is in `../gas_case6/LICENSE-GasModels.md` and
`scripts/gasnet2gtopt/cases/literature/LICENSE-GasModels.md`.  Only
numeric data is used; no GasModels code is vendored.  The reduction
merges parallel pipes and the two Voeren compressors, drops the
expansion candidates, and converts the resistances to gtopt's units
(see `scripts/gasnet2gtopt/cases/literature/README.md`).
