# gas_gaslib11_radial — gas network e2e case

Native gas elements generated by `gasnet2gtopt` (Python API
`build_native`) from `scripts/gasnet2gtopt/cases/literature/gaslib11_radial.gasnet.json` with the study
switches `{"compressor": "series"}`.

The expected objective is 295.410020. It comes from the prototype's
independent scipy/HiGHS LP of the same model, stored in
`scripts/gasnet2gtopt/cases/literature/expected.json`. The goldens under `output/`
come from gtopt and match it to 1e-5 relative, with pressures within
0.01 bar. `scripts/gasnet2gtopt/tests/test_gtopt_integration.py`
re-checks this against the expected values.
