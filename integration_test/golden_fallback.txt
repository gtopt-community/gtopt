# Explicit opt-outs for integration_test/cmake/compare_csv.cmake.
#
# A case that has an output_<solver>/ directory must contain a golden for
# every CSV in output/ -- a missing one FAILS the e2e_<case>_compare_* test
# (it used to fall back silently to output/, non-strict, which hid stale
# per-solver goldens).  Each line below allows ONE such fallback:
#
#   <case> <solver> <csv path relative to output/ | *>   # reason
#
# The fallback compares against output/<csv> non-strict and the test log
# says so.  Delete a line as soon as the golden exists (or the
# output_<solver>/ dir is removed); never add one without a reason.

# stale output_clp/*_s0_p0.csv files are removed and output_clp/ keeps
# only solution.csv -- the entries stay needed until then).
