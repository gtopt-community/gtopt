# Who uses GTOpt

Organizations, research groups and people who use GTOpt in their work.
If you use GTOpt, please add yourself: it helps other users find
peers, shows where the tool is used and guides what we build next.

## How to be listed

- **Pull request**: add a row to the table that fits, in alphabetical
  order, and open a pull request (adding a row needs no CLA).
- **Issue**: open an
  [“Add me to USERS.md” issue](https://github.com/gtopt-community/gtopt/issues/new?template=add_user.yml)
  and we add it for you.

A short description of what you use GTOpt for is enough. Do not include
confidential information; listing is voluntary and you can ask to be
removed at any time.
